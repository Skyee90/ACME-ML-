# Beginner Machine Learning Project – Rain Prediction (Logistic Regression)

This repository contains a beginner-level machine learning project where I built a **Logistic Regression** model to predict whether it will rain tomorrow based on given weather data.

This project was created as part of my learning journey in machine learning as a first-year Computer Science student.

## Problem Statement
The objective of this project is to predict **Rain Tomorrow (Yes/No)** using a classification model based on historical weather features.

## What I Did
- Explored and understood the dataset
- Performed basic data preprocessing
- Implemented a **Logistic Regression** model using **scikit-learn**
- Trained and tested the model to understand classification behavior
- Evaluated the model using basic performance metrics

## Tools & Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- scikit-learn

## Learning Objective
This project focuses on understanding:
- How classification works using logistic regression
- How features affect prediction outcomes
- The basic end-to-end machine learning workflow

The goal is learning and clarity, not model optimization.

Beginner-level learning project.
