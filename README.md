# Beginner Machine Learning Project – Linear Regression

This repository contains my first beginner-level machine learning project as a first-year Computer Science student.

The goal of this project is to understand the basic workflow of machine learning using a simple **Linear Regression** model.

## What I Did
- Implemented a linear regression model using **scikit-learn**
- Worked with data using **NumPy** and **Pandas**
- Performed basic data preprocessing
- Trained and tested the model to understand predictions
- Practiced the complete ML pipeline at a beginner level

## Tools & Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- scikit-learn

## Learning Objective
This project focuses on learning concepts rather than performance optimization.  
It helped me understand how data flows through a machine learning model.
